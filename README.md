# EMON Panel — GitHub Pages

এই ফোল্ডারটি GitHub Pages-এ Static Website হিসেবে ব্যবহার করা যাবে।

## ধাপ
1. সব ফাইল GitHub repository-তে আপলোড করো।
2. `index.html`-এ `FACEBOOK_LINK` অংশে তোমার আসল Facebook URL বসাও।
3. Repository Settings → Pages → Deploy from branch → `main` → `/root` নির্বাচন করো।
4. কিছুক্ষণ পর GitHub Pages-এর লিংক পাওয়া যাবে।

## গুরুত্বপূর্ণ
TikTok/YouTube/Facebook Follow বা Subscribe সত্যিই হয়েছে কি না এই সাধারণ ওয়েবপেজ স্বয়ংক্রিয়ভাবে যাচাই করতে পারে না। এখানে ব্যবহারকারী বাটনে চাপ দিয়ে পরের ধাপে যায়।
